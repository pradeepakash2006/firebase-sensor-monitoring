# Firebase Live Sensor Monitoring System

## Project Overview
An IoT-based monitoring system using ESP32 and DHT11 to collect temperature and humidity data and send it to Firebase.

## Technologies Used
- ESP32
- DHT11 Sensor
- Firebase
- Embedded C
- IoT

## Key Features
- Temperature monitoring
- Humidity monitoring
- Live sensor data updates
- Cloud data storage

## Domain
Embedded Systems and IoT
